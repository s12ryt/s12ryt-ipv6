# 專案文件與依賴表

| 路徑 | 用途 | 主要依賴 |
| --- | --- | --- |
| `cmd/s12ryt-ipv6/` | 前景 service、version、安全管理密碼重設與管理埠讀寫 CLI；處理 SIGTERM 並接 production runner | `internal/app`、`internal/admin`、`internal/secret`、Go 標準庫 |
| `internal/app/` | Linux production 組裝與生命週期、雙棧管理 listener、健康聚合、動態政策、連通性測試、drain 閉環、流量觀察、service lock及資料路徑 | `internal/admin`、`config`、`dns64`、`eventlog`、`firewall`、`ipv6resource`、`network`、`node`、`policy`、`proxy`、`secret`、`stats`、`webui` |
| `internal/config/` | 版本化 YAML 設定、預設值、嚴格驗證與原子保存 | `gopkg.in/yaml.v3` |
| `internal/ipv6resource/` | 前綴範本、canonical 地址、固定地址、動態池、刷新與 draining | `net/netip`、`crypto/rand` 相容 reader |
| `internal/policy/` | IPv4/IPv6/ULA/NAT64/本機及管理地址目的政策 | `net/netip` |
| `internal/secret/` | master key、AES-GCM 祕密庫、代理憑證及 Argon2id 管理密碼 | `crypto/*`、`golang.org/x/crypto/argon2` |
| `internal/auth/` | 單一管理 session、CSRF token 與雙層登入限速 | `crypto/rand`、`crypto/sha256`、`net/netip` |
| `internal/eventlog/` | JSONL 事件白名單、祕密去敏、檔案輪替與清除稽核 | Go 標準庫 |
| `internal/stats/` | 節點即時/累計統計、單節點/全部歸零及原子快照 | Go 標準庫 |
| `internal/dns64/` | IPv6-only DoT、A/AAAA 快取、目的政策、本地 DNS64 合成、RFC 7050 類型探測及健康監視 | `github.com/miekg/dns`、`internal/policy` |
| `internal/network/` | IPv6 address/local route/external 三模式交易、ownership 對帳、DAD、freebind，以及 Linux 介面、全球 IPv6 地址與核心路由候選偵測 | `internal/ipv6resource`、`github.com/vishvananda/netlink`、`golang.org/x/sys/unix` |
| `internal/firewall/` | 自有 nftables table 完整替換、動態開孔、關閉清理及外部 drop 診斷 | `github.com/google/nftables`、`golang.org/x/sys/unix` |
| `internal/proxy/` | IPv6-only 來源池/dialer、TCP/UDP 埠配置、SOCKS5 TCP+UDP、HTTP、mixed 與 system socket adapter | `github.com/things-go/go-socks5`、`internal/dns64`、`internal/policy` |
| `internal/node/` | 節點設定與生命週期、協定 handler 組裝、listener runtime、交易式更新及防火牆開孔協調 | `internal/proxy`、`internal/firewall`、`internal/policy`、`internal/secret` |
| `internal/admin/` | 管理密碼、單一 session HTTP/CSRF/限速、節點/資源/操作 API、登入保護的網路候選與前綴衝突 API、SSE、資源與操作協調器、Unix control socket/client及服務鎖 | `internal/auth`、`config`、`dns64`、`eventlog`、`firewall`、`ipv6resource`、`network`、`node`、`secret`、`stats` |
| `web/` | 繁中 React 管理 SPA：登入、總覽、節點、IPv6 資源、網路、日誌、SSE 增量刷新、瀏覽器專屬基礎／進階模式、自動命名、網路候選選單、可信 DNS64 預設、主題與響應式介面 | React、TypeScript、Vite、Vitest、Testing Library、Lucide |
| `web/go.mod` | 阻隔根 Go 模組掃描 `node_modules` 的工具邊界 | Go toolchain |
| `Dockerfile`、`compose.yaml` | Node/Go 多階段 image 與 host-network、NET_ADMIN、持久 volume 範例 | Docker BuildKit、Linux host |
| `install.sh` | GitHub Release 一鍵安裝/升級器：平台偵測、SHA-256、互斥鎖、健康檢查、UFW安全開孔與完整回滾 | GitHub Releases、curl、systemd、flock、nftables |
| `.goreleaser.yaml` | Linux amd64/arm64裸binary、tar.gz與checksums發布契約 | GoReleaser v2、`web/dist` |
| `.github/workflows/release.yml` | `v*` tag與手動版本發布；測試通過後建立tag，由tag事件唯一發布Release | GitHub Actions、Node.js、Go、GoReleaser |
| `deploy/` | systemd unit、共用根交易核心的offline installer、移除腳本及shell/release契約測試 | `install.sh`、systemd、Linux capabilities |
